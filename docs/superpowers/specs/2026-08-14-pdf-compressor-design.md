# PDF 压缩轻量小程序 — 设计文档

- 日期：2026-08-14
- 状态：待评审

## 1. 背景与目标

需要一款跨平台（Windows / macOS）的轻量 PDF 压缩桌面应用。典型输入为图片密集型的商业 PDF（如服装品牌 LOOKBOOK，单文件可达 1.2GB、每页 1920×1080），体积过大导致分享、传输、归档困难。

目标：以极轻的安装包（约 5~15 MB）提供本地离线、可调节档位、批量处理的 PDF 压缩能力。

## 2. 需求摘要

1. **图形界面（GUI）** 应用，非命令行。
2. **压缩档位可调**，由用户自行选择质量/体积平衡。
3. **文字层保留作为可选项**：默认保留文字（可搜索/可复制），仅在"极致压缩"档位下允许用户勾选"栅格化去除文字层"。
4. **完全离线**，压缩算法本地运行，不依赖云服务。
5. **批量处理**：一次导入多个 PDF 排队压缩。
6. **默认另存为新文件**（`原名_compressed.pdf`），保留原文件。
7. **压缩结果展示详细信息**：原大小、新大小、压缩率、页数、档位、文字层状态、耗时。
8. **架构可扩展**：为未来增加图片等多格式压缩预留接口（当前仅实现 PDF）。

## 3. 技术栈选型

| 层 | 选型 | 理由 |
|----|------|------|
| 桌面框架 | **Tauri 2**（Rust 后端 + 系统 WebView） | 不捆绑 Chromium，安装包 5~15 MB；跨平台一致 |
| 前端 | **Vue 3 + TypeScript + Vite** | 生态成熟、组件化开发效率高 |
| 压缩引擎 | **Ghostscript**（`pdfwrite` 设备） | PDF 压缩事实标准，`-dPDFSETTINGS` 提供现成档位，且默认保留文字层 |
| Ghostscript 集成方式 | **运行时检测 + 引导用户安装**（不随应用分发） | 规避 AGPL 分发合规风险，同时保持安装包极轻 |

### 3.1 Ghostscript 许可说明

Ghostscript 采用 AGPL 双许可。若将 Ghostscript 二进制随应用一起分发（sidecar 嵌入）且应用非 AGPL 开源，需购买商业许可。因此本项目**不打包 Ghostscript**，改为运行时检测系统是否已安装 `gs`，未安装则给出 Windows/macOS 官方下载引导。此方式下用户各自安装 Ghostscript，不构成"分发"。

### 3.2 压缩档位设计

| 档位 | Ghostscript 参数 | 预期效果 |
|------|-----------------|---------|
| 无损/轻度 | `-dPDFSETTINGS=/prepress` | 体积略降，质量零损失 |
| 平衡（默认） | `-dPDFSETTINGS=/ebook` | 显著缩小，肉眼难辨 |
| 极致压缩 | `-dPDFSETTINGS=/screen` + 额外降采样 | 压到很小，质量明显下降 |

附加开关：

- 图像 DPI 降采样上限（可选）。
- **栅格化去除文字层**（仅在极致压缩档位可选）：将页面栅格化为图片，显著降低体积，但文字不再可搜索/复制。

## 4. 架构设计

### 4.1 分层结构

```
┌─────────────────────────────────────────┐
│  前端 (Vue 3 + TS + Vite)               │
│  - 文件导入/列表 UI                      │
│  - 压缩档位选择、输出目录                 │
│  - 进度展示、结果详情                    │
└──────────────────┬──────────────────────┘
                   │ Tauri IPC (invoke)
┌──────────────────▼──────────────────────┐
│  Rust 后端                                │
│  - 压缩引擎注册表 (registry)              │
│  - 外部依赖检测 (gs 等)                   │
│  - 压缩任务调度 + 进度回调                │
│  - 结果统计                                │
└──────────────────┬──────────────────────┘
                   │ 子进程
             ┌─────▼─────┐
             │ Ghostscript│
             │ (gs 命令)   │
             └───────────┘
```

### 4.2 可插拔压缩引擎（核心扩展点）

为支持未来多格式（图片等），将"压缩"抽象为统一引擎接口：

```rust
trait CompressionEngine {
    /// 支持的扩展名，如 ["pdf"]
    fn supported_extensions(&self) -> Vec<&'static str>;
    /// 该格式可用的压缩档位定义（由前端动态渲染）
    fn presets(&self) -> Vec<Preset>;
    /// 执行压缩，返回结果统计
    fn compress(&self, input: &Path, preset: &Preset, opts: &Options) -> Result<CompressionResult>;
}
```

- 每种格式实现一个引擎，向后端**引擎注册表**注册；注册表按文件扩展名分发。
- 当前实现 `PdfEngine`（基于 Ghostscript）；未来 `ImageEngine` 等只需新增实现并注册。
- **前端按文件类型自适应**：导入文件后按扩展名分组，调用后端 `presets()` 动态渲染档位 UI，无需为每种格式硬编码界面。
- 批量队列、进度回调、结果统计（原大小/新大小/压缩率/耗时）设计为**格式无关**，所有引擎复用。

### 4.3 外部依赖检测抽象

将"Ghostscript 检测"泛化为"外部依赖检测"：每种引擎可声明其依赖的外部工具（如 `gs`、未来的 `vips`），启动时统一检测，缺失则给出对应安装引导。

- Windows 探测：`gswin64c.exe` / `gswin32c.exe`（PATH 及常见安装目录）。
- macOS 探测：`gs`（`/usr/local/bin`、`/opt/homebrew/bin`、`/opt/local/bin`）。

### 4.4 模块职责

| 模块 | 职责 |
|------|------|
| `engine/` | 引擎 trait 定义 + 注册表 |
| `engine/pdf.rs` | Ghostscript 引擎：命令构造、执行、结果解析 |
| `detect/` | 外部依赖检测（gs 探测、版本读取、安装引导文案） |
| `task/` | 压缩队列调度、进度事件、错误聚合 |
| `stats/` | 读取新 PDF 统计页数/大小，计算压缩率 |

## 5. 数据流

```
用户拖入 PDF → 前端列出文件(名称/大小/页数)
    → 用户选档位 + 输出目录 → 点击"开始压缩"
    → 前端 invoke('compress', {paths, preset, opts})
    → Rust 按扩展名分发到 PdfEngine，逐个调用 gs(事件回调进度)
    → 每完成一个 → 回传 {原大小, 新大小, 压缩率, 页数, 档位, 文字层状态, 耗时}
    → 前端更新进度条与结果详情
    → 全部完成 → 导出新文件列表
```

## 6. 错误处理

- **`gs` 未安装**：阻止压缩，弹窗引导（Windows/macOS 分别给官方下载地址）。
- **单个文件压缩失败**（损坏 PDF、加密 PDF 等）：不中断队列，标记该项失败并显示原因，继续后续文件。
- **加密 PDF**：提示需要密码，暂不处理（v1 范围外）。
- **输出路径无权限 / 磁盘不足**：捕获并给出明确中文提示。
- **Ghostscript 崩溃/超时**：设置超时与进程清理，报告具体错误码。

## 7. 结果详情展示

压缩完成后每项展示：

- 原始大小 → 压缩后大小
- 压缩率（如 `-87.3%`）
- 页数
- 压缩档位
- 文字层状态（"文字可搜索" / "已栅格化"）
- 处理耗时

## 8. 测试策略

- **单元测试（Rust）**：`gs_detect` 路径探测逻辑、命令参数构造（不同档位/开关组合）。
- **前端测试**：组件渲染、IPC mock。
- **集成测试**：用样例 PDF 验证三档压缩输出的体积与可打开性。

## 9. 未来扩展（不在本版范围）

- 图片压缩引擎（JPEG/PNG/WebP/AVIF 等）：依赖取向（纯 Rust `image-rs` vs 外部工具 `libvips`/ImageMagick）留待实现时决定，当前仅预留 trait 接口与注册表。
- 加密 PDF 密码处理。
- 更多压缩档位自定义（细粒度 DPI / 质量滑条）。

## 10. 范围边界（YAGNI）

本版本**不做**：云同步、账号体系、在线预览、图片压缩、视频压缩、命令行模式、自动更新。
